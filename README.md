Minimal Ayu Tokyo Night themed Hyprland setup.

## Programs

List of programs and tools I use:

- Window Manager - hyprland
- File Manager - yazi
- Terminal - kitty
- Shell - fish
- App Launcher - rofi
- Status Bar - waybar
- Notification Center - swaync
- Lockscreen - hyprlock
- Power Menu - wlogout
